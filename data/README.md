# Імпорт товарів

`perfumes_import.csv` зведено з переданих PDF. Він містить 11 товарів, повні описи, ноти та посилання на фотографії флаконів. Усі позиції позначені як новинки; за потреби змініть `is_new` на `false`.

Перед продажем замініть у колонці `price` усі значення `0.00` на реальні ціни в гривнях. Цін у вихідних документах не було, тому їх навмисно не вигадано.

Для акції заповніть `regular_price` більшою за `price`; для ручного бейджа хіта встановіть `is_bestseller` у `true`.

Колонка `variants` уже є у CSV. Для кількох обʼємів вкажіть їх в одному полі, наприклад, `30:500|50:700|100:1200`. Ціна після двокрапки — у гривнях.

У адмінці відкрийте **Парфуми → Імпортувати CSV** і завантажте цей файл. Повторне завантаження оновлює товари за полем `slug`.

Зовнішні фото потрібні лише для перевірки імпорту. Для продакшену завантажте власні або надані постачальником файли, на використання яких магазин має права.
